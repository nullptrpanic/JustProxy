隐私政策

更新及生效日期：2026 年 11 月 11 日

JustProxy 是运行在用户 iPhone 上的 HTTP 代理工具。应用无需注册或登录，不集成广告或第三方统计 SDK，也不向开发者运营的服务器上传代理流量、连接记录或统计数据。

1. 代理请求如何处理

当你开启代理并将客户端配置为使用 JustProxy 时，应用会在设备上处理客户端发来的请求，并按请求转发到相应目标服务器。目标服务和你使用的网络可能按照各自的隐私政策处理这些请求。HTTPS CONNECT 流量以隧道方式转发；JustProxy 不安装用于解密 HTTPS 的证书。

2. 会话统计与保存期限

为展示会话流量，应用在本机内存中记录上传和下载字节数，以及最近连接的目标主机、端口、请求方式和流量，最多保留最近 50 条连接记录。这些信息不由应用写入持久化文件，也不上传给开发者。新代理会话会重新统计；应用进程结束后，内存中的记录随之释放。

3. 网络信息和权限

应用读取设备当前可用的本地网络地址，以提供监听地址选择。本地网络权限用于访问局域网目标。JustProxy 不申请定位权限，不读取 Wi-Fi 名称，也不申请照片、通讯录、麦克风或相机权限。

4. 你的控制方式

你可以随时在主界面关闭代理。结束应用进程可清除内存中的会话记录。应用没有开发者服务器上的用户账号或个人档案需要删除。

此网站由 GitHub Pages 托管，未使用分析脚本或广告。访问网站时，GitHub 可能处理提供托管服务所需的技术信息，具体见 GitHub 隐私声明。

如果你主动通过邮件联系我们，你提供的邮箱和邮件内容将用于回复咨询、处理问题和必要的后续沟通。请勿发送密码、令牌或敏感的代理流量内容。如希望删除主动提供的支持邮件，可通过下方邮箱提出请求。
