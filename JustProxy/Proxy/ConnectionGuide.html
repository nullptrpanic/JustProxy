Common questions

Does opening this page mean I am using the proxy?

This page confirms that the proxy address is reachable. Complete the proxy setup above to forward requests from clients that support and follow those settings.

Do I need to turn on Personal Hotspot?

No. Devices can use the same Wi-Fi network if it allows them to communicate. When using Personal Hotspot, connect the other device to it and enter the hotspot address shown in JustProxy.

What if I cannot access the internet after setup?

Return to JustProxy, check that the proxy is running, and confirm its address and port. The address may change after switching networks, and some apps need separate proxy settings. Turn off the device’s manual proxy when you stop using JustProxy.
