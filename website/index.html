HTTP PROXY

简单开启，清楚查看。

JustProxy 是一款 iPhone HTTP 代理工具。开启代理后，将显示的地址和端口填入客户端的代理设置，即可转发请求，并在应用中查看会话流量和最近连接。

开始使用

  1. 将 iPhone 和客户端连接到可互通的网络。热点不是必需条件，也可以使用同一 Wi-Fi 网络。
  2. 打开 JustProxy，使用自动选择或选择一个可用的监听地址。
  3. 点击主界面的大按钮开启代理。
  4. 在客户端的 HTTP 代理设置中填写应用显示的 IP 地址和端口 8080。
  5. 在客户端浏览器中打开该代理地址，可查看适配当前设备的详细配置说明。

流量与连接

“流量”页面显示上传、下载的累计字节数，以及最近连接的目标、端口和流量。只有通过 JustProxy 转发的请求会计入这些统计。

连接不上时

确认代理处于运行状态，客户端填写的 IP 和端口与应用一致，并且两台设备之间允许网络通信。部分网络会隔离设备，蜂窝网络地址也不一定能被其他设备访问。切换网络后，请重新检查监听地址。

后台运行

使用时建议保持 JustProxy 在前台。iOS 可能在后台暂停或结束应用；返回应用后，请检查代理状态，必要时重新开启。

停止代理

再次点击主界面的大按钮即可关闭代理。使用结束后，也请关闭客户端的手动代理设置。请仅向信任的设备提供代理访问。
